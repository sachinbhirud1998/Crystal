## Documentation standard

Each record must include the problem statement, objectives, architecture review, decisions, dependencies, implementation summary, validation, security and cost review, risks, lessons learned, next steps, sign-off, and commit reference. Platform Engineering owns the milestone record and reviews it at every state change.
