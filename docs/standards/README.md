## Purpose and scope

These standards define the minimum working agreement for all Project Crystal repository changes. They apply to documentation now and to future authorized implementation work. An accepted ADR may supersede a standard only for its explicit scope.

## Review ownership

Platform Engineering owns this standards set and reviews it at each milestone boundary or when a material operating-model change is proposed.
