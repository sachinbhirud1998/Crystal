# Documentation

This directory is the operational and engineering knowledge base for Project Crystal. Documents should be concise, versioned with the work they describe, and written for the person who must make or support a decision later.

| Directory | Purpose |
| --- | --- |
| `milestones/` | Scope, outcomes, and exit criteria for delivery stages. |
| `runbooks/` | Repeatable operational procedures. |
| `standards/` | Mandatory engineering conventions. |
| `troubleshooting/` | Symptom-led investigation guidance. |
| `operations/` | Review checklists, risk registers, rollback, and decision records. |

Use the templates in each relevant directory and link related ADRs, issues, and pull requests.

## Documentation ownership and review

Platform Engineering owns this documentation system. Each durable document must identify an accountable owner, a review date, applicable scope, and revision history. Records that affect architecture must link to `architecture/`; material architecture decisions are captured only through ADRs.
