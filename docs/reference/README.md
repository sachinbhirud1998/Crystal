# Current-state reference

## Purpose

Provide a concise, controlled inventory of the Project Crystal environment after the completed landing-zone milestone.

## Scope

These records capture observed current state only. They do not define future implementation or replace architecture decisions.

## Current status

Repository Foundation and AWS Organizations and Landing Zone are complete. All later platform domains are not started.

## Architecture

The reference set covers Organization, accounts, IAM Identity Center, primary region, Terraform state posture, and deployment status.

## Engineering notes

Update these documents when completed state changes, and do not infer unrecorded configuration details.

## Validation

Validate records through authorized AWS administrative access and completed milestone evidence.

## Known limitations

Account IDs, OU memberships, user identities, SSO URLs, policies, and resource inventories beyond the landing zone are not retained here.
