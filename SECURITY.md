# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, sensitive architecture details, or security incidents in public issues or pull requests. Report them privately to the project maintainers using the approved team communication channel.

Include a concise description, affected paths or components, safe reproduction information, impact assessment, and any suggested mitigation. A maintainer will acknowledge the report and coordinate next steps.

## Security expectations

- Never commit credentials, tokens, private keys, or sensitive exports.
- Review `.gitignore` and staged changes before every commit.
- Keep access scoped to the minimum required for the active milestone.
- Record material security design decisions as ADRs.

Project Crystal does not yet contain deployed infrastructure. This policy applies to repository content and all future platform work.
